# ps-ads-tool

Vibe coded ADS tool for quickly looking at PLC variables with minimal dependency.

Search, read, write, watch and chart TwinCAT PLC variables on a PC that only has TwinCAT ADS installed. One PowerShell script, no other installs.

## Usage

Copy the three files into one folder, then run:

- `AdsTool.bat` for the GUI
- `AdsTool-Console.bat` for the console version

Optional: `-NetId <id or route name>`, `-Port 851`, `-Theme Dark|Light`, `-AdsDll <path>`
